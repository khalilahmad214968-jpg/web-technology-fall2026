## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer:The <ol> tag makes an ordered list with numbers like 1, 2, 3, while the <ul> tag makes an unordered list with bullet points. I would use <ol> when the order matters, such as my top 3 goals for this semester or steps in a cooking recipe. I would use <ul> when the order does not matter, like a list of my hobbies or a shopping list.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer:Every <img> needs an alt attribute because it shows text on the screen if the picture fails to load or the file path is broken. It is also used by blind or visually impaired people who use screen reader software to hear what is in the image.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer:A relative link like hobby.html only gives the file name or path inside the same website folder without the domain name. An absolute link starts with https:// and gives the full web address of an outside website on the internet.
